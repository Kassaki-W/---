# 12306 自动购票助手

本地 Web 服务形态的 12306 辅助购票工具。到点自动完成「查询 → 提交订单 → 轮询占座」，
**支付由人工在官方页面完成**。仅限本人及直系亲属自用、不收费、不对外提供服务。

方案设计与需求细节见 [12306自动购票助手-方案设计.md](12306自动购票助手-方案设计.md)。

## 使用

```bash
npm install
npm start        # 服务起在 http://127.0.0.1:12306，自动打开浏览器
```

免安装绿色包（无需装 Node）：`node build.js` 生成 `dist/12306购票助手-绿色版/`，
整个文件夹拷走，双击「启动购票助手.bat」即用。

## 首次使用流程

1. **登录**：控制台「登录 / 会话」页生成二维码 → 12306 官方 App 扫码确认；
2. **乘车人**：添加乘车人（身份证校验位自动核验、加密存储、界面只显示后四位），
   在官方 App 确认实名后点「标记核验」（未核验不能被任务选中）；
3. **设置**：填写提前量 Δt（先用非热门车次实测在途耗时后填入，软件不预设）；
4. **任务**：新建任务（候选车次按优先顺序、开抢时刻自行查证车站起售时间）→「武装」；
5. 到点自动开抢：命中候选 → 提交 → 占座成功 → 桌面通知 → 官方页面人工支付。

## 架构（对应方案 7.1）

```
web/    控制台静态页（原生 HTML/JS，五页签）
src/
  main.js            入口：FastAPI→Express 服务 + 静态托管 + 引擎启动
  api/               本地 REST API（routes / session / passengers / tickets / tasks / orders）
  scheduler/         调度引擎：状态机、时钟校准、任务主循环、休眠阻止
  session/           会话生命周期：扫码登录、加密持久化、失效全局阻断
  platform/          平台访问层：唯一与 12306 通信的模块（接口变更只改这里）
  db/                node:sqlite 建表 + AES-256-GCM 加密
  notify/            通知（桌面系统弹窗，纯本机，数据不出机）
data/                运行数据（SQLite、密钥、按天日志）——不出本机
```

## 技术栈

Node.js v24（Express + 内置 `node:sqlite` + `node:crypto`），无构建链，前端零依赖。

## 关键红线（方案 2.3 / 6.5 / 8）

- 不做自动支付、不做验证码绕过、不做账号池 / IP 代理池；
- 席别不降级、不用官方候补；提交串行单发、失败退避不提速；
- 身份证号与登录凭证加密存储，日志不落原文，通知不含个人信息；
- **全部数据只存本机**：通知为桌面弹窗，不经任何网络通道外发；
- 遇人机校验一律转人工介入，不设计任何绕过手段。
